# Legado Digital — Protótipo web 0.1

Abra `index.html` no navegador do computador para uma demonstração. Para testar no Safari do iPhone e adicionar à tela inicial, publique os arquivos em hospedagem HTTPS estática (por exemplo, GitHub Pages ou Netlify). Depois, no Safari, toque em Compartilhar > Adicionar à Tela de Início.

## Limitações importantes
- Protótipo apenas; sem API de IA, autenticação, servidor ou publicação na App Store.
- Dados salvos em localStorage do dispositivo; não há sincronização, backup confiável nem criptografia de aplicativo.
- O seletor de papéis é uma simulação e **não constitui controle de acesso seguro**.
- Não inserir dados reais, históricos privados ou documentos confidenciais.
- A futura versão comercial exige backend seguro, consentimento dos envolvidos, autenticação e revisão jurídica.
